# Java OOP Practice – CSCI185
This repository contains Java programming exercises completed as part of my Computer Programming II coursework.
The project focuses on applying Object-Oriented Programming (OOP) principles such as inheritance, composition, and class relationships.

## Concepts Covered
- Object-Oriented Programming (OOP)
- Classes and objects
- Inheritance
- Composition
- Constructors
- Encapsulation
- Relationships between classes
- Problem solving using Java

## Tools Used
- Java
- IntelliJ IDEA

## Purpose
To strengthen understanding of object-oriented design and learn how to model real-world relationships using Java classes.
This project demonstrates how multiple classes interact through inheritance and composition to build structured and reusable code.
